# 🛒 Ecommerce Retail Data Analysis

This project analyzes ecommerce retail data using **Python, Pandas, NumPy, and Matplotlib** to understand sales performance, customer behavior, product performance, payment patterns, and business trends.

## 📊 Key Analysis
- Sales by Year, Month, Category & Customer Segment
- Top 10 Products by Sales
- Payment Method & Payment Status Analysis
- Device-wise Sales Analysis
- Customer Satisfaction Analysis
- Product Return Rate Analysis
- Average Order Value by Customer Segment

## 🛠️ Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📁 Files
- `Ecommerce_Retail_Data_Analysis.ipynb` — Complete analysis notebook
- `Dataset/ecommerce_retail.csv` — Dataset
